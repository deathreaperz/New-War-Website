Getting started

Installation

01

Install the base game

Make sure Command & Conquer: Red Alert 2 and the Yuri's Revenge expansion are both installed and patched to their latest official version.

02

Run the New War installer

Download the installer above and point it at your existing Yuri's Revenge install folder. It handles the Ares DLL and all mod files automatically.

03

Launch from the New War shortcut

Use the New War desktop shortcut created by the installer, not your original game shortcut, to make sure the mod loads correctly.

04

Join the community

Hop into our Discord for patch notes, matchmaking, and to report anything that looks broken.
