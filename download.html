Before you start

Required base game files

You must have a legal copy of Red Alert 2: Yuri's Revenge installed and patched to version 1.001. The following files must be present:

FileNotes
BINKW32.dllBink video library
BLOWFISH.dllEncryption library
ra2.mixBase game data
ra2md.mixYuri's Revenge data
language.mixBase game language
langmd.mixYuri's Revenge language
gamemd.exeMust be the official v1.001 executable — Original, TFD, or Ultimate Collection patches all work. NPatch or other modified executables are not supported.

Optional — add original game soundtracks: theme.mix & thememd.mix

Read before unpacking

Warnings

⚠ Old version installed

Do not unpack if you have New War version 0.43 or lower installed. Those versions are no longer supported and are incompatible — remove them completely before proceeding.

⚠ Other modifications present

Do not unpack if you have other modifications applied to your Yuri's Revenge installation. Remove or undo all modifications before proceeding.

⚠ CnCNet for Yuri's Revenge installed

Do not unpack if you have CnCNet for Yuri's Revenge installed in the same directory. New War ships its own CnCNet Client.

Getting started

Installation

01

Prepare your Yuri's Revenge installation

Make sure all required files listed above are present and your gamemd.exe is the official v1.001 patch. You can install into your existing Yuri's Revenge folder, a copy of it, or a new empty folder with the required files copied in.

02

Read the warnings above — then unpack

Download the archive from ModDB and unpack all files to your chosen Yuri's Revenge directory. If prompted to overwrite, allow it.

03

Launch with NWLauncher.exe

Run NWLauncher.exe — not the original gamemd.exe. It's best to configure your settings in the Options menu before starting your first game.

04

Report issues & join the community

If something isn't working, check the Discord for quick fixes before filing a bug report.
